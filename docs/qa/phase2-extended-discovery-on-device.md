## Notes

A. Check 3 attribution: a range found by more than one source is listed once, under the highest-priority source (manual, then evidence, then probe). 10.0.4.0/24 always has Hue Bridge evidence on this LAN, so the probe's hit on it cannot be seen in the UI; that it would hit is consistent with 10.0.4.1 serving the same UniFi page on port 80 as the three /24 gateways the probe did report. Showing every source per range is a design question, not fixed.

B. Manual editor: with one or more ranges in the list, a valid entry with no helper text leaves the "Add range" button under the keyboard (b04-duplicate.png); the field only scrolls itself into view when there is an error or note. Back hides the keyboard and the button is then reachable. Not fixed (usability, Director's eye).

C. After Stop the headline reads "0 other ranges checked" (it counts swept ranges only) and a range that never started (10.0.9.0/24, PENDING when Stop came) reads "stopped", the same as the one that was running. Wording question; not fixed. Part A note C ("Scanned in 25 s" after a Stop) applies here too.

D. "N on another subnet" counts off-subnet rows seen in the latest run only (17 off-subnet rows stored, "4 on another subnet" after a probe-off run). By design (`HomeStats`), recorded for the Director.

E. The probe-toggle supporting text wraps "/16" across lines ("every /24 in your /" then "16"), at 1.0. Director's eye.

F. During a scan uiautomator dumps take about 11 s and return the pre-scan tree (the expanded range summary still present while the screen shows the scanning disc). This looks like the accessibility snapshot not updating while the radar animates; it may or may not affect TalkBack, whose check is still pending from Part A.

G. The network header reads "Wi-Fi (tap to show the name, needs location)": location permission is not granted on the phone at present (Part A showed "CHi"). Not changed by this run.

H. Spec 8.3 still says "using 25 s per range"; the code now uses 16 s (fix 6d71fb3). The spec text is for its owner to update.
